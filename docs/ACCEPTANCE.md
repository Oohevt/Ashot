## 固定判据

普通截图：真实 .app 框选和窗口采集，保存后重开，像素尺寸/边界正确、无工具覆盖层；复制后粘贴到真实外部应用，保留证据。

编辑：矩形、箭头、中文文字、不透明遮盖可添加、修改、撤销重做；导出/复制与预览一致。PNG 不含可恢复的图层。

长截图：article/table/code 三类各连续 3 次实际屏幕采集；每个完整结果 1000×7680，120 行全部保留。oracle 比较所有像素（sRGB），RGB 任一通道误差 >3 视为不同，整体不同比例 ≤0.001；另人工检查接缝。尺寸、少行、重复或错位均不得通过。阈值不因结果改变。

素材为独立生成的 PNG，实际验收在原生文档窗口显示，采集仅接收 ScreenCaptureKit 屏幕帧；禁止把素材文件直接传入拼接器冒充桌面验收。

失败恢复：至少覆盖失去重叠、动态内容干扰、目标窗口变化，显式提示并保留已有结果，用户可结束或重试。超限可明确拒绝，不能错误宣告成功。

生命周期：100 次实机触发/取消，无残留覆盖层、焦点失控、持续采集；记录进程内存并检查持续增长。

权限只能正常授权；缺失权限或机器标未验证；最低部署 macOS 14 只表示构建目标，不能冒充对应系统已实测。

## 完成门槛

入口成功、测试数 ≥3、skipped=0、摘要校验成功，并且上述桌面验收全部通过；任一必需能力未验证或失败，状态保持未完成。

每份实机证据必须关联具体构建标识，代码变化后复验受影响项目。初始任务 0 的验证结果只证明框架/检查器可用，不证明应用功能。
