## 改动

1. **长截图坐标**：选区、显示器和目标窗口统一使用 ScreenCaptureKit 的左上原点坐标；全局转换用 `SCDisplay.frame`，窗口内裁剪只减窗口原点。目标窗口取框选截图时的快照，避免遮罩激活后 Stage Manager 缩略窗口坐标参与选区判断。开始采集时通过 AppKit 协作激活把输入交给目标应用；后台缩略窗口变换不再直接判为用户移动窗口；开始长截图时收起主窗口，避免Ashot主窗口与源文档在Stage Manager中争夺前台。
2. **Retina PNG**：采集的实际像素倍率随裁剪、编辑、撤销/重做和长图传递，保存与剪贴板都写入每轴 DPI。倍率由实际像素/逻辑尺寸计算，支持 1×、2×及不同每轴倍率，未写死 144 DPI。
3. **标注色彩**：标注渲染与拼接共用源 RGB 色彩空间策略，Display P3 不再被硬编码为 sRGB；有效源空间不可用于位图时保留 sRGB 回退。
