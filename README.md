# Ashot

macOS 原生截图工具，当前开发中。默认快捷键 `⌥ A`，可在主窗口修改。

构建：`./script/build_and_run.sh --build-only`。运行 `dist/Ashot.app` 或执行 `./script/build_and_run.sh run`。构建后若没有实例在运行，会自动把 `dist/Ashot.app` 同步到 `/Applications/Ashot.app`（开机自启的登录项指向那里）；有实例在跑时跳过同步。

本地构建使用已配置的 Apple Development 证书，指纹存放在 `config/signing-identity.txt`（仅公开证书标识，不含私钥）。固定签名身份让重新构建后的屏幕授权能匹配同一应用；已实测确认换构建后授权仍然有效。没有证书时构建会报错。

如果授权是在临时（ad hoc）签名时期给的，系统会把授权钉死在那一个二进制的 cdhash 上，之后无论怎么重新构建、怎么在系统设置里点开关都会一直提示权限不足。此时需要先执行 `tccutil reset ScreenCapture com.oohevt.Ashot` 清掉旧记录，重新构建并启动，再授权一次。判断依据：`/Library/Application Support/com.apple.TCC/TCC.db` 中该条目的 `length(csreq)` 为 40 表示被 cdhash 钉死，约 160 表示绑定的是证书要求。

验证：`./scripts/verify.sh`；真实桌面验收另见 [ACCEPTANCE.md](docs/ACCEPTANCE.md)。构建或单元测试通过不表示桌面验收完成。

区域截图覆盖层支持鼠标悬停自动框选：光标停在独立对话框、应用窗口、顶部菜单栏上时显示候选轮廓，单击即锁定为选区，随后与手动框选完全一致（`W` 复制 / Enter 编辑 / Esc 取消）；直接拖动超过 8 pt 则始终按手动框选处理，空白处不会自动选全屏。候选只覆盖当前实际可见的系统区域，Dock 自动隐藏或边界不可靠时不给候选、回退手动框选。裁剪使用触发截图时冻结的画面，输出为当时可见的像素，不补出被遮挡内容。

区域截图框选后：按 `W` 直接复制到剪贴板并关闭，不进编辑器；按 Enter 或点击“编辑截图”进入标注；也可点击“长截图”，缓慢向下滚动静态页面，完成后点击“结束并编辑”。不能确认接缝时暂停并保留已拼接结果；请回到上一位置后重试，或结束保存。

截图或长截图完成后自动进入剪贴板，可直接 `⌘ V` 粘贴。编辑器提供矩形、箭头、文字、不透明遮盖；选择工具可拖动移动标注，右下角调整端点，文字可点击“修改文字”。标注、撤销和重做后自动更新剪贴板，也可点击“复制”；支持 PNG 保存。

首次访问其他应用画面需要系统授权：系统设置 → 隐私与安全性 → 屏幕与系统音频录制 → Ashot。按系统提示重新打开应用。应用不会替用户修改系统权限。

设置页（状态栏菜单「设置…」、`⌘ ,` 或主界面「设置…」）：可同时隐藏 Dock 图标与顶部菜单栏图标（开启后仅剩截图快捷键入口，请先确认快捷键可用）；可开关开机自启（`SMAppService` 登录项，状态实时显示）。

限制：单显示器内选择；长截图只支持静态内容、单向竖直向下，选区避开固定标题和滚动条。容量上限 1600 万像素，超限保留已有结果并提示结束。

部署目标 macOS 14，当前只在 macOS 27 / Apple Silicon 开发；其他系统与多屏验收状态见 BLOCKED.md。没有第三方依赖、账户、云端、录屏或翻译。

独立测试文档应用为 `dist/AshotFixture.app`，显示 fixtures 中的文章/表格/代码图片。它与截图程序进程分离，PNG 素材不会被读取进截图或拼接实现；独立 oracle 只用于验收。
